## Authoritative release limitations

- Research evidence and threshold conventions do not guarantee creator success; F17 only sorts and F18 describes robustness/confidence.
- History can be unavailable/immature; cumulative views cannot substitute for historical V(30), and YouTube search is not a census.
- NexLev is optional/provider-derived; unavailable semantic REST remains unavailable. No private CTR, retention, owner analytics, true demographics, revenue/RPM or monetization certification is core evidence.
- Both live providers and real-niche coverage remain unverified without configured keys and source-specific permissions. API/policy contracts can change; amendment acceptance was not established here.
- Watches express stored intent. Scheduler, automatic collection/startup, global installation and remote deployment are absent.
- Trusted local owner namespaces are not authentication. Use separate DB/process and OS protection for private profiles, data and backups.
- Validation used Windows/Python 3.12.14 and existing locked dependencies; fresh network installation, other platforms, remote deployment, formal external security audit and off-device backup were not validated.
- Large synthetic frames make substantial validation/read SQL queries; Deep production-scale and live latency remain unverified.
