# Phase 6 decision contract (phase6-v1)

Written before production implementation, against phase-5-verified
99c90d6dec642b74ce4942130d1e4fe18ec35009. The seven frozen research specifications
remain authoritative; Third_Pass_Gap_Audit section C supersedes the older automatic
F17 recommendation wording. F1–F16, floor and F19–F23 are unchanged.

Evidence supports further consideration under the tested assumptions. It does
not predict creator success. All calculations consume retained, known-at-cutoff
stored evidence, with no HTTP or public research tool registration.

## Separate axes and rules

Keep performance (F1/F2/F3), ordinary floor (F5/floor), repeatability (F7/F20),
entrant access/exposure (F4/F19/F21), breadth (F8), concentration (F6/F9),
history/momentum (F10–F13/F20/F21), gaps/saturation/packaging, idea depth (F15),
faceless production, task burden (F16), source feasibility, rights, platform
policy, factual/editorial burden, pilot downside (F23), and evidence confidence.
Results contain source run/formula/annotation IDs, raw values, states, coverage,
conflicts, warnings, sensitivity comparisons and concise supports/concerns/unknowns.

There is no universal profitable view level, healthy HHI or labor limit. Numeric
decision rules must be caller supplied, versioned and justified by a declared
research goal/reference. Ungraded observations stay ungraded. Existing explicit
feasibility/risk rubrics can supply reviewed concerns. Creator fit is separate
and cannot alter canonical metrics or generic synthesis.

States: supported, supported_with_caveats, mixed_evidence, weak_under_goal,
insufficient_evidence, high_execution_burden, high_rights_or_policy_dependency,
history_immature. These are research states, not approval or legal verdicts.
Absent essential demand/access/floor/classification/production/source/risk
evidence blocks unqualified support. Immature history is a distinct gate.
Unresolved material rights, policy or factual burdens block unqualified support;
creator capacity mismatch is an additional fit concern, not a niche rejection.

## F18 and confidence

Preserve blueprint F18: the fraction of **comparable completed predeclared
specifications** with the same generic decision, with decision-flip reasons.
Report numerator/denominator, unavailable/planned/omitted specifications and
each changed axis. This is specification agreement, not probability, statistical
confidence interval, Bayesian posterior or calibrated model confidence.
No specification agreement when there are no comparable variants.

The component matrix matters more than this fraction. Separate measured coverage,
quality and agreement: mature outcomes, observed channels, classified topics,
language/faceless/live/membership/continuity review, independent groups, history
requirements, routes/overlaps/weak cases, threshold/boundary/missingness stability,
field conflicts, qualitative/comment samples, production and separate risk reviews.
Provider labels do not establish human visual verification.

Ordinal rubric: high requires complete declared critical evidence, verified
critical classifications and ownership, mature required history, no unresolved
conflicts, and completed stable checks in every declared required sensitivity
family. Medium permits useful partial evidence and noncritical gaps. Low applies
to missing critical evidence, conflicts, provider-only critical review, sensitive
or unavailable required checks. These conservative implementation rules are
explicit heuristics, not research-calibrated cutoffs. A reliable weak conclusion
can have high confidence. More runs never automatically improve the grade.

## Sensitivity contract

Plans are declared before synthesis and bounded: quick <=8, standard <=24,
deep <=48 one-at-a-time variants. No Cartesian product. Identity includes the
parent, family, changed option, selected input IDs, code/config versions and
comparison rules. Reuse analysis_runs/results/outcomes; no new tables required.
Base runs remain immutable. Retention, revocation and frozen discovery checks
propagate through ancestry on every replay.

Route subsets deduplicate canonical entities; include all, official only,
NexLev excluded, winner routes excluded, weak/suggested excluded, semantic
excluded and per-route subsets. Report overlaps, omissions, pagination/cap
limitations and weak cases. No retrieved route is a YouTube census.
Provider T1/T2/T3/classification/similarity ablations remove relevant dependencies
and rerun supported formulas. T4/T5 never enter core scoring. If complete
reclassification/alternative evidence is unavailable, report
insufficient_without_provider, not a fabricated official classification.

Duration 6/8/10 minutes, current size <50k/<100k and broad/practical/narrow
boundaries require separately predeclared frozen compatible cohorts. An 8-minute
frame cannot invent missing 6-minute candidates. Explicit alternative cohorts
must disclose omissions and threshold/version/inclusions/exclusions. Goal
variants use caller supplied goals. Compare metrics, counts, concentration,
floor, breadth and available qualitative findings. Unavailable alternatives
stay explicit. Never choose a canonical boundary by observed winning results.

Missing binary outcomes reuse F22 lower/upper finite-frame bounds. Compare both
with the same declared goal rule, retain known-only summaries; unknown is never
zero, a miss, median-imputed or assumed independent. Bounds say nothing about
undiscovered entities. Independence compares provisional canonical units with
documented grouped units only, without inventing ownership. Qualitative alternate
seed/reduced/expanded samples reuse Phase 5 manifests and stored available reviews;
missing expansions are reported. Comment counts, videos, route/order and source
independence remain visible, with no universal comment weight.

Material change means a declared decision-rule classification changes, a
decision changes, or a caller configured raw metric tolerance is exceeded.
No tolerance means raw shifts are reported without inventing materiality.

## Policy freshness and retention

Only retained dated policy annotations can supply substantive policy evidence.
Stale or absent evidence returns policy_refresh_required and blocks unqualified
support. Optional independent policy clock receipts contain snapshot ID and
retrieval/refresh dates only, with their own declared retention and provenance;
they can diagnose staleness but never revive expired policy text or favorable
findings. No live browse runs inside this engine.

## F17 sorting firewall

Optional F17 uses explicit caller supplied versioned weights and linear external
benchmark endpoints; clamp (raw-low)/(high-low) to [0,1], invert for lower-is-better.
Expose raw, endpoints, direction, clipping, normalized value, weight, missing
state and included/excluded dimensions. Only validated internal numeric formula
values are accepted, with an explicit allowlist. No provider RPM/revenue,
monetization or opaque T4 score. Unknown essential dimensions =>
insufficient_dimensions; optional omissions => partial_index using disclosed
included-weight denominator, only when explicitly enabled. Complete =>
sorting_index_available. F17 executes after generic synthesis and confidence,
cannot modify either, and never approves/rejects a niche.
