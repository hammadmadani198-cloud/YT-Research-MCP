# 3. NON-NEGOTIABLE RESEARCH PRINCIPLES

The system must NEVER pretend to know public competitor:

- impressions
- CTR
- audience retention
- average percentage viewed
- watch time
- returning viewers
- actual audience overlap
- traffic-source breakdown
- private search terms
- actual RPM
- actual revenue
- per-video subscriber conversion
- recommendation exposure

Do not estimate them as facts.

The following must also be enforced:

- current subscriber count ≠ subscriber count at breakout
- account creation date ≠ niche-entry date
- current lifetime views ≠ historical V(30)
- missing ≠ zero
- immature outcome ≠ failure
- playlist membership ≠ binge behavior
- provider labels ≠ verified truth
- search result totals ≠ search volume
- low supply ≠ automatically low competition opportunity
- one viral video ≠ repeatable niche
- high competition ≠ automatically bad niche
- faceless ≠ easy
- AI-assisted ≠ automatically cheap
- public asset availability ≠ reuse permission
- confidence ≠ success probability

# 15. THIRD-PASS FORMULAS

## F19 / C90 — paired attempt/calendar exposure

For an entrant cohort report together:

- channels with >=1 goal hit
- total eligible uploads
- uploads hitting the goal
- attempts per creator
- elapsed time
- zero/low-output entrants
- unresolved outcomes

Never present channel ever-hit fraction alone.

Support first:

- 5 uploads
- 10 uploads

and calendar windows such as 90 days.

## F20 / C91 — post-hit baseline change

Merge into failure-floor/follow-up analysis.

Compare:

- pre-hit mature median
- post-hit mature median
- same outcome age
- anchor excluded

Return `insufficient_history` when required observations do not exist.

Do not claim causal audience transfer.

## F21 / C92 — winner replacement

Implement schema/support now.

Analytics should return `insufficient_history` until comparable windows exist.

Eventually report:

- replacement share
- incumbent persistence
- verified entrant share

Do not invent historical values.

## F22 — finite-frame missing-outcome bounds

For an enumerated cohort:

`lower = known_success / total_frame`

`upper = (known_success + unknown) / total_frame`

Return these as bounds over the researched frame.

Do not call them confidence intervals or population probabilities.

## F23 / C93 — pilot downside/evidence runway

Optional creator-input module.

Allow voluntary:

- available hours
- setup cost
- per-video cost
- max acceptable loss
- revision range
- pilot size

Do not convert public views into expected income.
