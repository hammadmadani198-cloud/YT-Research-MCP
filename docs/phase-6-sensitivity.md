# Phase 6 immutable sensitivity plans

Plans use phase6-oat-v1 and are declared by the decision cutoff. Quick allows at
most 8 derived comparisons, standard 24, deep 48. The run budget bounds actual
recalculations; omissions are reported. There is no Cartesian product.

Each saved phase6-v1 sensitivity run references the canonical base, changed family,
changed option, source run IDs, input identity and comparison version. It carries
frozen discovery fingerprints, retained ancestry and input-bounded expiry.
Identity includes the rubric, policy/classification context, projected metrics
and software version. F17 weights and creator fit cannot influence generic
comparisons. Base runs and cohorts remain immutable.

## Comparisons

- Routes: all, official-only, NexLev-excluded, winner-oriented-excluded,
  weak/suggested-excluded, semantic-excluded; deep also tests individual routes.
  Channel recruitment scopes its stored uploads. Canonical entities are deduped;
  occurrences, unique/overlapping candidates, collection outcomes, page scope,
  remaining-page indicators and capability limitations remain visible.
- Provider: remove NexLev T1/T2/T3, remove provider classifications, remove provider
  similarity. Provider-dependent reviewed annotations are removed transitively
  and supported qualitative calculations rerun. No replacement is fabricated.
  T4 similarity can support an attributed auxiliary review; removing that review
  may change the differentiation axis, but never imports its score into metrics.
- Thresholds: caller-provided goals plus predeclared compatible 6m/8m/10m and
  <50k/<100k frozen cohorts. Missing alternatives report insufficient comparable
  evidence; an 8m frame cannot reconstruct omitted 6m candidates.
- Boundaries: frozen broad/practical/narrow cohorts require stable boundary IDs,
  nodes, inclusions, exclusions and classifier versions. Other recruitment rules
  must stay fixed. Cross-boundary history/qualitative claims require compatible
  alternate source runs. Source ancestry for those runs is retained.
- Missingness: F22 lower/upper and known-only video/channel summaries, compared
  with the caller's binary rule. No random/median imputation or zero substitution.
- Ownership: documented-group-only projected outcomes versus provisional canonical
  channels, with F8/F9/F19 shifts. Known groups and unknown relationships remain
  visible. F21 also exposes documented-group winner-set replacement/persistence diagnostics
  when retained winner IDs exist; per-winner entrant annotations stay unknown.
  Canonical historical F21 context is held fixed unless a separately compatible
  historical comparison is supplied; no historical group membership is invented.
- Qualitative: deterministic alternate seed and reduced review budget; deep also
  expanded budget using available stored annotations. Original sample manifests
  remain unchanged. Expired alternative inputs report unavailable, not a new claim.

Output states are stable, materially_changed, insufficient_without_provider,
insufficient_comparable_evidence or budget_omitted. Material means a declared
rule flips, an axis/state changes, or an explicit caller tolerance is exceeded.
Raw comparisons include metric state, count, value and details even when no
material threshold is declared. Context held fixed is disclosed per comparison.
Weak ordinary floors and failed/pending/unknown cases remain in every applicable
subset. Retrieved discovery is never asserted to represent all of YouTube.
